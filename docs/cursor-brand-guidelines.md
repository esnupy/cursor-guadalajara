# Cursor Brand Guidelines

#design

## Logo usage

- Logos are Cursor’s most visible marker and consist of the Cube and the wordmark
- The cube has two main versions, a monocrhome “D version and a flat polychrome 2.5D version
- 2D is our primary logo and user in most cases, while 2.5D is reserved for larger applications and is an icon or
  artwork
- Horizontal is the primary lockup, while vertical is used only when centered alignment is more appropriate
- Use avatars on social media or other profile representations. Avatars come in 2D and 2.5D, dark, light, and pure white
- Use the 2D avatar in most cases. Reserve 2.5D avatars for large-scale applications
- We prefer the light version of the avatars for many social profiles to keep things from feeling too dark. In some
  cases, a pure white background looks even cleaner
- Use the circle version of the avatar when platforms crop avatars into a circle
- Use the official logo lockups. Don’t create your own
- Use enough space around the logo. Don’t make it look oversized
  - Bad example: Don’t display the logo in a context where it feels oversized
  - Good example: Do use enough space around the cube (equivalent to at least 1/2 cube width)
- Use the Cube at modest sizes with enough breathing room to achieve a refined feeling
- Use the light or dark favicon based on the user’s color theme
- ASCII logos and animations are available for use across product, social, and other applications. Animate at 4fps with
  display with 120% line-height, when possible

## Typography usage

- Cursor Gothic is our official brand typeface, and should be user whenever possible. When not possible ‐ such as in
  Google Docs or Google Slides - Helvetica is a suitable fallback
- Choose a suitable type scale. First pick a base font size. The rest of the type hierachy (your type scale) extends
  from this. Do not use arbitrary text sizes
- Use a minimum of font sizes. Where possible, use the same font size. If secondary text needs to be denoted, a
  secondary text color is preferred
  - Bad example: Don’t use more than one parameter (e. g. both font size and text color) to create hierachy
  - Good example: Use one paremeter (e. g. text color) tp create hierachy
- In general, type follows the pattern of: larger type = tighter tracking, tighter line-height
- Always use a logo ligature when placing the logo alongside text. Size the logo using simple geometric ratios relative
  to the text or by using notes on the same typographic scale, never arbitrary scaling
- Balance line lengths manually when needed, by inserting a carriage return or reducing the width of the text box

## Color usage

- Cursor’s brand colors are neutral and understated with a bright orange accent. Use neutrals as the base, and keep the
  accent very sparing so it feels sharp and intentional.
- Cursor’s colors system is built for balance between light and dark. Neither theme is default.
- Use both where possible, and let context guide the decision. A sunlit bus shelter calls for light mode; a screen-first
  or low-light environment may call for dark
- Use neutrals for most buttons and large area CTAs
  - Bad example: Don’t use accents too liberally, such as for buttons
  - Good example: Use neutrals primarily, such as for buttons
- Use the accent to add just that little something to compositions.
  - Good example: A pricing section where we have 4 tiers, and the third one is the recommended one, so we display a
    “Recommended” label in accent color to stand out of the rest
- You are ancouraged to use pure white `#FFFFFF` or pure black `#000000` when needed. Sometimes it helps make to break
  out of midtone purgatory

## Layout & Grid

- Use grids with intentional margins and gutters
- Outer margins define the frame of the content. For a harmonious feel, set margins in proportion to the overall
  document width (e. g. 3%, 4%, 5%)
- Smaller documents require proportionally larger outer margins than larger documents
- Grid columns (and optionally, rows) bring structure and clarity. As with outer margins, define gutters relative to
  overall document width
- Favor slightly narrow gutters than typical. A dense grid signals a professional, power-tool sensibility when handled
  with precision
- As with outer margins, smaller documents need proportionally larger gutters
- Default to top-left alignment. If it’s good enough for code, it’s good enough for your layout
  - Good example: Position: Top-Left; Text-align: Left
- In alternate cases, use centered alignment intentionally, when balance or rhythm calls for it
  - Good example: Position: Center-Center; Text-align: Center

## Photography

- Warm, not overproduced, and precise in intent. Use natural light and candid shots to ground Cursor in real energy.
  Film and disposable cameras introduce spontaneity, giving cultural moments their authentic texture.

## Video

- When creating lower-thirds for names and titles, use Cursor Gothic at regular weight, a single size, and tracked-in
  letter spacing. Nice and simple
- Do not position lower-thirds arbitrarily. If legibility is an issue in the bottom-left, move them to the bottom-right
  instead
- Title cards follow the same general principle as lower-thirds: one font-size. Align layout top-left if appropiate
- Don’t use extremely loose or tight outer margins
- Use a cozy 4% outer margins
- Text cards or interstitials should follow the same layout and type principles
- Make colors lively and dynamic, never dull or washed out

## Copy & Voice

- Cursor speals with quiet confidence: clear, concise, and apporachable. We explain things simply, without hype or
  excess. Technical when needed, light when possible. Always professional, sometimes witty, never forced.
  - Good example: Say things simply and directly. Be lcear and concise, but complete. Stay professional and
    considerate
  - Bad example: Don’t oversell or exaggerate. Don’t try too hard to be funny or casual. Don’t hide meaning in jargon
    or corporate speak
- Use sentence case for all headings, labels, and titles outside the Cursor IDE. No need to capitalize words outside of
  proper nouns. Use curly or “smart” quotes rather than straight quotes. Use em dashes (—) surrounded by a space
  - Good examples: Improved Agent tools, steerability, and usage visibility. Bringing the Cursor Agent to Linear. New
    API key. Only run when mentioned. We’re updating our limits on “Auto” for individuals. We perform the attention
    operation — which requires reading the cached keys and values
  - Bad examples: Improved Agent Tools, Steerability, and Usage Visibility. New API Key. Only Run When Mentioned.
    We're updating our limits on "Auto" for individuals. We perform the attention operation - which requires reading
    the cached keys and values

## Motion

- A gentle ease-out spring animation is used for most transition timing functions, from translations to fades.
  - Good example: `--ease-out-spring: cubic-bezier(0.25, 1, 0.5, 1);`
